# ideos_2026 reference dataset

- **Source**: IDEOS project parquet layers (bucket/prefix tracked by the sibling
  `proj-IDEOS-metas` repo, not here), 2024 assessment year, S3 sync version `2026.v01`.
- **Synced via**: `proj-IDEOS-metas/scripts/sync_from_s3.sh` (separate repo — ohipy never
  touches S3 directly or holds AWS credentials).
- **Converted via**: `scripts/convert_ideos_layers.py` (parquet -> chl-schema CSV layers).
- **Committed here**: only `layers/csv/` (chl-schema, drives the R baseline; single source of
  truth). The ohipy-native variant is NOT committed — `tests/parity/ideos_fixture.py`'s
  `build_ohipy_native()` derives it on the fly into a throwaway temp dir on every test run (9
  files get a column rename via `CHL_TO_OHIPY`, the rest are copied verbatim). This mapping is
  test-local plumbing, distinct from ohipy's engine-level declared-rename mechanism
  (`data/layers.csv`'s `fld_category_out`/`fld_val_out`), which only recognizes ohipy-native
  column names and can't consume the legacy chl/R ones directly.
- **R reference fixture**: `tests/comparative/fixtures/ideos_2026/baseline.csv`, generated by
  `tests/comparative/calculate_scores_ideos.r` inside the `ohicore-r-env` Docker image.
- **Regenerate**: `OHI_AUTO_GENERATE_FIXTURES=1 uv run pytest tests/test_ideos_parity.py -m ideos_parity -v`
  (requires Docker + an already-downloaded parquet dir, `IDEOS_PARQUET_DIR`).
